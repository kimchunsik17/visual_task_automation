# B6 배치 — Tier 2 사이드바 내비게이션 (14개)

`icon-generation-prompts.md` §2 의 #38~51. 노드가 아닌 **첫 배치**다.
내비는 18px 로 렌더되고 항상 화면에 떠 있으므로, 노드 아이콘보다 **한 단계 굵고 단순하게** 그려야 한다.

## 이 배치에서 원래 계획을 바꾼 것 — 톱니 배지 폐기

원 모티프는 #43 웹훅 관리와 #45 스케줄 관리에 각각 **"우하단 톱니 배지"** 를 붙여
"관리 페이지"를 표시하려 했다. 세 가지 이유로 폐기했다:

1. **배지가 본체와 겹친다.** 라인 아이콘은 넉아웃이 없어서 겹치는 배지는 항상 충돌로 보인다
   (B4·B5에서 반복 확인). 24px 안에서 본체 + 비겹침 배지를 넣으려면 본체를 15px 이하로
   줄여야 하는데, 그러면 18px 렌더에서 본체가 안 읽힌다.
2. **6px 배지에 톱니 6개는 그려지지 않는다.**
3. **#48 설정(큰 기어)과 의미가 겹친다.** 톱니 3개는 과하다.

대신 **B1+B2 에서 노드가 시계와 지구를 모두 비웠기 때문에** 내비가 그 모티프를 그냥 쓸 수 있게 됐다:
- #45 스케줄 관리 → 시계 (노드는 달력+▷ / 모래시계를 쓰므로 충돌 없음)
- #43 웹훅 관리 → 갈고리 + 엔드포인트 (노드는 수렴 팬을 쓰므로 충돌 없음)

### 렌더해보고 고친 것 (3건)

1. **`nav-settings` — 기어가 아니라 배의 조타륜(helm)으로 읽혔다.**
   처음엔 "원 + 긴 스포크 8개 + 작은 중심원"으로 그렸다. 스포크가 길고 허브가 작으면
   그건 기어가 아니라 조타륜이다.
   → **두꺼운 링(r=7.5) + 큰 중심 구멍(r=3) + 링 바로 밖 짧은 돌기(길이 2)** 로 바꿨다.
   기어는 "두꺼운 링 위의 짧은 돌기", 조타륜은 "작은 허브에서 뻗은 긴 스포크"다.

2. **`nav-templates` — 세로 책 3권이 통계 막대그래프와 똑같았다.**
   높이만 다른 세로 라운드 사각형 3개는 그냥 막대그래프다. #47 통계와 나란히 놓으면 구분 불가.
   → **펼친 책**(책등 + 좌우 페이지 곡선)으로 전면 교체.

3. **`nav-app-builder` — 이웃보다 시각적으로 가벼웠다.**
   대각선 획 하나 + 작은 별 2개뿐이라, 14개가 세로로 늘어선 목록에서 유독 흐리게 보였다.
   → 팁 근처에 짧은 테두리 획을 추가해 무게를 맞췄다.
   **교훈: 나란히 놓이는 아이콘 세트는 "읽히는가"뿐 아니라 "무게가 같은가"도 봐야 한다.**

### WebhookManagerPage 를 함께 고친 이유

내비 "웹훅 관리"를 갈고리로 바꾸고 나니 **같은 기능의 페이지 제목은 여전히 `Globe`** 여서
내비와 페이지가 서로 다른 그림을 쓰게 됐다. 내가 만든 불일치이므로 함께 맞췄다.
`.title-icon` 은 CSS 에 정의돼 있지 않아 lucide 기본값 24px 이 적용되고 있었으므로
`size={24}` 를 명시해 현재 크기를 유지했다.

### 남은 중복 — 정직한 평가

| 아이콘 | 현재 상태 | 판단 |
|---|---|---|
| `Box` | ChatSidebar · TutorialSandbox · AppBuilderPage 3곳 | ⬜ **B8 에서 해소 필요** |
| `TextCursorInput` | AppBuilderPage 에서 Input Field / Text Area 두 곳에 재사용 | ⬜ **B8 에서 해소 필요** |
| `Clock` | 9곳 (스케줄러·통계·실행기록·평가 등) | ✅ **문제 아님** |
| `Play` | 13곳 (전부 "실행" 버튼) | ✅ **문제 아님** |
| `Send` | 5곳 (전부 "전송" 버튼) | ✅ **문제 아님** |

`Clock` · `Play` · `Send` 가 여러 곳에 남은 건 **의도한 결과**다. 원래 문제는
"의미가 다른 기능이 같은 아이콘을 쓴다"였는데(스케줄 시작 vs 대기 vs 관리),
지금 남은 건 전부 같은 의미다 — 시각·실행·전송. 만국 공통 UI chrome 은 손대지 않는다는
§1 원칙 그대로다. **따라서 실제로 남은 충돌은 `Box` 와 `TextCursorInput` 둘, 모두 B8 몫이다.**

`Sidebar.jsx` 의 `Puzzle` 과 `customNodes.jsx` 의 `Settings` 는 현재 도달하지 않는
폴백이다(레지스트리 6종 모두 `icon` 을 가짐). 앞으로 `icon` 없이 추가되는 레지스트리 노드를
위해 의도적으로 남겨뒀다.
